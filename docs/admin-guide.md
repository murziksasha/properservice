# Посібник адміністратора

## Вхід

1. Відкрийте `/admin/login`
2. Введіть пароль з `ADMIN_PASSWORD`
3. Якщо увімкнено 2FA — введіть 6-значний код з Authenticator
4. Після входу — Dashboard зі статистикою, **Live health** і швидкими діями

## Двофакторна автентифікація (2FA / TOTP)

Опційний другий фактор для входу в адмінку. Код генерує застосунок (Google Authenticator, Aegis, 1Password тощо).

### Увімкнення з адмінки (рекомендовано)

1. Увійдіть у адмінку (поки без 2FA)
2. **Налаштування → Безпека · 2FA**
3. Введіть пароль адмінки → **Увімкнути 2FA**
4. Відскануйте QR (або скопіюйте secret / otpauth URI) у Authenticator
5. Введіть 6-значний код → **Підтвердити і увімкнути**
6. Secret зберігається в `data/admin-totp.json` (не в `site.json`, не в git)
7. На **Огляд** у Live health з’явиться «2FA TOTP увімкнено»
8. Наступний логін — пароль + код з застосунку

### Вимкнення з адмінки

**Налаштування → Безпека · 2FA → Вимкнути 2FA** — пароль + поточний код 2FA. Видаляє `data/admin-totp.json`.

### Увімкнення через `.env` (ops / Docker)

Якщо задано `ADMIN_TOTP_SECRET`, він **має пріоритет** над файлом; UI setup/вимкнення недоступні.

1. Згенеруйте **base32**-secret (або візьміть з UI / `.env.example`: `JBSWY3DPEHPK3PXP`)
2. Додайте в Authenticator (TOTP, 30 с, 6 цифр) або:
   `otpauth://totp/ProperService:admin?secret=ВАШ_SECRET&issuer=ProperService&algorithm=SHA1&digits=6&period=30`
3. У `.env`:
   ```env
   ADMIN_TOTP_SECRET=ВАШ_SECRET
   ```
4. Перезапустіть Node / PM2 / Docker

### Вимкнення через `.env`

Приберіть або закоментуйте `ADMIN_TOTP_SECRET` і перезапустіть. Якщо лишився `data/admin-totp.json` — 2FA знову візьметься з файлу (вимкніть у UI або видаліть файл).

### Безпека

- Secret показується **один раз** під час setup (QR + копіювання)
- Confirm/disable вимагають пароль адмінки; disable — ще й валідний TOTP
- Off-site backup: якщо копіюєте весь `data/`, туди потрапить і `admin-totp.json` — тримайте backup захищеним
- Поки 2FA вимкнено, поле «Код 2FA» на логіні можна лишити порожнім

## Заявки

**Адмінка → Заявки** (Огляд у меню)

- Усі заявки з форми зворотного дзвінка (`data/leads.json`)
- Працює **навіть без SMTP** — телефон зберігається локально
- У записі: час, телефон, `pagePath` (звідки відправлено форму), чи пішов email, **нотатка** оператора
- Фільтр: Нові / Опрацьовані / Усі
- **Оброблено** / **Видалити** / click-to-call / нотатка (blur → save)
- Фільтри: статус, **сьогодні / 7 днів**, пошук по телефону, **CSV**
- UTM (якщо було в URL), історія дій (created / handled / note)

### Лист на пошту магазину (SMTP)

Після ліда (якщо налаштовано `SMTP_*` / `MAIL_TO`) приходить лист з службовою інформацією:

- телефон (і `tel:`-посилання), час, **ID заявки** (той самий, що в журналі)
- сторінка сайту та заголовок вкладки, Referer
- IP, User-Agent, мова браузера
- посилання на `/admin/leads` (якщо задано `SITE_URL`)

Без SMTP заявка все одно з’являється в журналі з міткою «без email».

## Замовлення

**Адмінка → Замовлення**

- Замовлення з **сторінки товару** (`/shop/[id]` → форма «Замовити»)
- Файл: `data/orders.json` (окремо від заявок)
- У записі: час, телефон, коментар, снапшот товару (назва, ціна, код), чи пішов email, **нотатка**
- Працює **навіть без SMTP** — замовлення лишається в журналі (`email ✓` / `без email`)
- Фільтр: Нові / Опрацьовані / Усі
- **Оброблено** / **Видалити** / click-to-call / нотатка / посилання на сторінку товару
- Фільтри: статус, період, телефон, **CSV**
- Live health на **Огляд** (потрібна сесія): SMTP, Telegram, 2FA, SITE_URL, кнопка **Тест SMTP**

### Як клієнт замовляє

1. Відкриває опублікований товар на сайті
2. Вводить телефон (+ опційний коментар)
3. Натискає **Замовити**
4. Менеджер бачить запис у **Замовлення** і (якщо SMTP) лист на `MAIL_TO`

Кількість завжди 1 — деталі узгоджуються по телефону. Кошика немає.

## Навігація адмінки

- Бічна панель **завжди видима** під час прокрутки контенту (скролиться лише основна колонка).
- На великих екранах кнопка **згорнути** (іконки ←→ біля логотипу) ховає підписи пунктів — лишаються **піктограми**; стан зберігається в браузері.
- На вузьких екранах — кнопка-меню (гамбургер) і виїжджаюча панель.

## Медіатека

**Адмінка → Медіатека**

- Сітка файлів `public/uploads/` (метадані — `data/media-index.json`)
- Upload з автоматичною оптимізацією (JPEG → WebP; PNG зберігається; GIF без змін)
- **Тематичні папки** (віртуальні): створити / перейменувати / видалити зліва; файли лишаються `/uploads/імʼя` (URL не ламається). Видалення папки переносить файли в «Без папки».
- **Сортування**: новіші / за назвою / **вручну (DnD)** — ручний порядок у межах обраної папки (не в «Усі файли»).
- **Розмір** (пресет resize): Загальне, Товар, Логотип, Hero, OG
- **Роль** (призначення): Товар, Hero, Блок сторінки, Лого, Відгуки, OG, Інше + **теги**
- У полях зображень — **«З бібліотеки»** (фільтр папка + роль)
- Copy URL / мета (роль, папка, теги) / видалення
- Нові файли доступні **одразу** (без `pm2 restart`)

## Меню

**Адмінка → Меню**

- **Шапка сайту** — пункти header (додати / видалити / порядок)
- **Навігація послуг** — вкладки послуг (`slug` → URL `/slug`)
- Перетягування за **⠿**, стрілки на клавіатурі (↑↓ на ⠿)
- **Ctrl+S** — зберегти

## Сторінки

**Адмінка → Сторінки**

- Додайте сторінку (назва + опційний slug)
- **видима** — публікація на сайті
- **Конструктор** — редагування секцій
- **↗** — відкрити публічну сторінку
- **⧉** — дублювати сторінку (копія прихована)
- Головну (`slug` порожній) **не можна** видалити

### Конструктор

- Додавання / приховування / **DnD** (⠿) / ↑↓ / **⧉** дубль секції
- **contentHtml**: якщо заповнено — на сайті лише HTML (секції ігноруються); порожньо → секції (політика тощо)
- **Preview** — iframe зі збереженою версією (оновлюється після Save)
- HTML-заголовки, зображення (URL + upload + preview)
- Розмір заголовків і масштаб тексту
- **Hero**: рядки «про сервіс», форма callback, active slug, зображення
- **Contacts**: телефони/соцмережі секції, кнопка **↻ З налаштувань**; порожні списки → fallback з Налаштувань на сайті
- **Callback / shop-grid**: заголовок, кнопка, placeholder / subtitle
- **Ctrl+S** + попередження при закритті вкладки **і** переходах по адмін-меню
- Збереження з **updatedAt**: конфлікт іншого сеансу → повідомлення оновити сторінку

## Товари

**Адмінка → Товари**

- Додайте товар: назва, ціна, **код** (опційно, мін. 2 символи), **категорія** (опційно), опис, фото (з preview; upload з пресетом **Товар** 1200×900)
- **Пошук** по назві, опису, категорії й коду
- На публічній сторінці товару — форма **Замовити** (телефон + коментар)
- **Фільтр видимості:** Усі / Опубліковані / Приховані
- **Сортування списку** (ціна, назва) — лише для перегляду в адмінці, **не** змінює порядок на сайті
- **DnD ⠿** для порядку в каталозі — активне, коли пошук порожній, фільтр «Усі» і сортування «За порядком каталогу»
- «Опубліковано» керує видимістю на `/shop`
- «Зберегти всі» / Ctrl+S записує список (включно з видаленнями)

### Публічний магазин `/shop`

- Пошук товару, сортування (порядок каталогу / ціна ↑↓ / назва), фільтр за категорією (якщо задані)
- Параметри в URL: `?q=…&sort=price-asc&category=…` (можна ділитися посиланням)
- Кнопка **Скинути** очищає фільтри

## Налаштування

**Адмінка → Налаштування**

- SEO title / description, логотип, favicon
- Години, адреса, email, copyright, map, відгуки
- **Телефон шапки** + **додаткові телефони** (список)
- **Соцмережі** (Viber / Telegram / Instagram / YouTube + іконка)
- Політика конфіденційності
- **Backup**: експорт / імпорт / server snapshots

## Backup (laptop / Keen DNS)

1. Кожне **Зберегти** створює auto-snapshot у `data/backups/` (оберіть `BACKUP_KEEP`)
2. **Налаштування → ⬇ Експорт JSON** — файл на ПК
3. **Snapshot** — ручна копія на сервері
4. **Restore** — відновлення з snapshot (спочатку pre-restore копія поточного стану)
5. **×** — видалити snapshot; **Імпорт** — з файлу (Zod)
6. CLI: `npm run backup` / HTTP cron — див. `docs/deploy.md`

Також копіюйте `data/site.json`, `data/leads.json`, `data/orders.json`, `data/backups/`, `public/uploads` **на інший диск** (off-site) — див. `docs/deploy.md`.

Для sitemap/OG/JSON-LD у production задайте `SITE_URL` (повний URL сайту).

## Поради

- Після збереження Preview оновлюється сам; публічну вкладку — Ctrl+F5
- Зображення ≤ 5 MB: JPEG, PNG, WebP, GIF; на upload JPEG → WebP, розмір за пресетом поля (товар / лого / hero / …)
- Не вставляйте `<script>` у HTML — санітизуються при показі
- Для LAN: `COOKIE_SECURE=false`; опційно `ADMIN_IP_ALLOWLIST`
- На мобільному сайті — sticky «Зателефонувати»
