# Посібник адміністратора

## Вхід

1. Відкрийте `/admin/login`
2. Введіть пароль з `ADMIN_PASSWORD`
3. Після входу — Dashboard зі статистикою

## Меню

**Адмінка → Меню**

- **Шапка сайту** — пункти header
- **Навігація послуг** — вкладки послуг (slug = URL `/slug`)

Збережіть зміни кнопкою «Зберегти».

## Сторінки

**Адмінка → Сторінки**

- Додайте сторінку (назва + опційний slug)
- **Конструктор** — редагування секцій:
  - додавання / приховування / порядок ↑↓
  - HTML-заголовки, зображення (URL або upload)
  - розмір заголовків і масштаб тексту
- Головну (`slug` порожній) **не можна** видалити
- «Перегляд» відкриває публічну сторінку

Незбережені зміни позначаються жовтим написом; браузер попередить при закритті вкладки.

## Товари

**Адмінка → Товари**

- Додайте товар, ціну, опис, фото
- «Опубліковано» керує видимістю на `/shop`
- «Зберегти всі» записує список (включно з видаленнями в UI)

## Налаштування

**Адмінка → Налаштування**

- Логотип, favicon
- Години, адреса, email, телефон шапки
- Copyright
- **Посилання на відгуки** — якщо заповнено, кнопка «Більше відгуків» веде на цей URL

## Поради

- Після збереження оновіть публічну сторінку (Ctrl+F5)
- Зображення ≤ 5 MB, формати: JPEG, PNG, WebP, GIF
- Не вставляйте сторонні `<script>` у HTML-поля — вони будуть видалені при показі
